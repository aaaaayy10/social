## 계산과 개인정보

세부 PDF는 124쪽으로 앞 62쪽과 뒤 62쪽의 행 수와 Y 좌표를 대조했다. 병합된 이용자 정보를 다음 이용자번호 전까지 이어받았으며 페이지 경계를 보존했다. 프로그램 현황 PDF의 환불 열은 2쪽에 있으므로 페이지 간 같은 Y 좌표로 연결했다. 환불보고서는 각 금액 열의 X 좌표로 읽어 빈칸이 다른 열로 이동하지 않도록 했다.

만 나이는 파일의 마지막 입금일이 아닌 자료 기준일 2026-11-04로 고정했다. 생년월일의 달력 유효성과 나이 0~120세 범위를 검사했다. 누락과 미래 날짜는 임의 수정하지 않고 나이 집계에서 제외했다. 성별은 명부의 남/여를 사용하고 전체·강좌별 이용자번호를 중복 제거했다.

`난타초급/난타 초급`, `난타중급/난타 중급` 등 띄어쓰기 차이만 프로그램 현황표에 맞춰 연결했다. 명부의 ‘찾아가는 시니어 디지털 스쿨’, ‘치매예방교실’은 현재 현황표 및 환불보고서에 없는 별도 프로그램이다.

개인 이용자번호·생년월일 및 PDF 원문은 공개 소스나 웹 데이터에 넣지 않고 집계값만 사용했다. 임시 원본 추출·행 연결 자료는 Git 제외된 `.tools/nov4-*`에만 있다.

## 혼합 금지

1. 현재 등록 현황의 1,318명과 명부 실인원 945명은 범위가 다르다. 이를 동일 모집단으로 나누거나 현재 등록 실인원으로 단정하지 않는다.
2. 명부 강좌별 연인원 1,810명은 프로그램별 이용자 중복 제외 합계이다. 수납 기록 2,645건은 반복 납부를 포함한다. 둘 다 출석 횟수 합산이 아니며 출석 연인원은 자료가 없다.
3. 명부 환불금액 열은 모두 미기재이다. 실제 환불 0원으로 간주하지 않는다.
4. 별도 환불보고서의 입금액은 해당 보고서의 범위이며 전체 수납금액이 아니다. 명부의 85,853,000원에 합산하거나 환불액을 차감하지 않는다. 자료 간 개인 식별자 대조가 불가능하므로 중복·보완 관계를 단정하지 않는다.
5. 환불보고서 456명은 원본 인원 합계로 개인 중복 제외 실인원이 아니다. 환불일도 없어 월별 환불액을 만들지 않는다.
6. 이전 성별·연령 현황표는 새 명부 통계로 교체했다. 과거 표의 이용 횟수(20,220)와 이번 중복 제외 인원을 비교·합산하지 않는다.
