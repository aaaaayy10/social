화면의 금액 카드·정렬·순위·비교표·CSV는 이 최신 금액표만 사용한다. 명부의 금액 열 합계 85,853,000원은 별도 원본 검산값이며 화면 금액에 합산·차감하지 않는다. 이전 같은 이름의 2쪽 파일 추출값(입금액 13,680,000원 등)은 폐기된 표시값이다.

## 개인정보 및 재처리

명부는 앞 62쪽과 뒤 62쪽의 행 수와 Y 좌표를 대조했고, 등록 현황의 환불 열은 2쪽의 같은 Y 좌표로 연결했다. 개인 식별자와 생년월일은 공개 파일에 포함하지 않는다. 생년월일은 달력 유효성과 나이 0~120세 범위를 검사하고 오류를 임의 수정하지 않는다.

파일명이 같더라도 매번 첨부 원본을 다시 읽어 SHA-256, 쪽수, 헤더를 확인해야 한다. `.tools/nov4-payments.json` 같은 이전 추출 파일을 현재 첨부로 간주하지 않는다. 최신 금액 재추출과 검산은 `.tools/reread-payments.mjs`, `.tools/correct-current-payment-pdf.mjs`에서 수행했다. 명부를 재집계할 때에도 금액표를 구버전 추출값으로 덮어쓰지 않아야 한다.
