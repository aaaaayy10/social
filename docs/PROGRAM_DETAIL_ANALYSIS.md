# 세부 분석 자료와 계산 기준

- 출처: 사용자가 제공한 `통합 문서1.pdf`, 144쪽.
- 앞 72쪽: 이용자번호, 이용자 대상구분, 생년월일, 입금일자.
- 뒤 72쪽: 수납 대상구분, 프로그램명, 금액, 환불금액.
- 페이지 `n`과 `n+72`의 행 개수와 Y 좌표가 일치하는지 검증한 후 연결했다. 이용자 정보의 병합 셀은 다음 이용자번호가 나타날 때까지 이어지며 페이지 경계에서도 유지했다.
- 두 대상구분은 실제로 다를 수 있어 각각 집계했다.
- 원본 개인정보와 PDF는 public에 복사하지 않았다. `src/data/program-details.json`에는 집계값만 저장한다.

## 해석

- 수납 기록은 신청 건수나 현재 수강 인원과 다르다. 반복 수납과 환불된 기록도 포함한다.
- 환불 빈칸, 환불 0원 기재, 환불 양수는 구분한다. 환불 합계는 기재된 값을 합한다.
- 환불 처리일은 없으므로 월별 환불은 해당 수납 기록의 입금월에 배정한다. 실제 환불월로 해석하지 않는다.
- 평균 만 나이와 연령 분포는 마지막 입금일인 2026-10-23 기준으로 계산하고 이용자번호 중복을 제외한다. 누락 또는 계산 결과 0~120세 범위를 벗어난 생년월일은 제외한다.
- 성별 항목은 없다. 기존 성별 이용 현황표는 집계 단위와 기간이 다르므로 등록자 성별로 대체하지 않는다.
- 프로그램명은 PDF 원문 표기를 유지한다.
- 이전 2026-10-22 신청·수납 현황 자료 및 별도 성별·연령별 이용 현황표와 합산하지 않는다.
