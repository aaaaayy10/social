# RF·수기 출석 통합 — 2026-11-04

## 범위와 분류

첨부 `2026년 1월~10월 출석자 명단.pdf`는 367쪽의 스캔 운영일지이다. 실제 포함 월은 2~7월 및 9~10월이다. 1월 출석 자료는 없으며 2월 일본어 초급 일지도 없다. 누락을 0명으로 채우지 않는다. 8월은 사용자가 건강100세만 운영했다고 확인했으므로 수기 35개 프로그램은 운영0회·출석0명, 비율은 계산 불가로 표시한다.

RF 10개: 에어로빅, 요가1/2, 필라테스1/2, 건강체조, 생활체조, 건강100세 운동교실, 힐링노래교실, 라인댄스1. 기존 RF 날짜별 자료와 현재 수납인원 스냅샷을 그대로 사용한다. 신규 운영일지 안의 같은 RF 프로그램 출석은 합산하지 않는다. 사용자가 라인댄스2는 수기로 변경하도록 명시했으므로 기존 A1811 RF 자료는 통합 조회에서 제외하고 첨부 수기 자료만 사용한다. 원본 RF JSON 자체는 수정하지 않았다.

현재 등록 45개 프로그램 중 위 RF10개를 제외한 35개는 수기이다. 사물놀이 초·중급은 현재 등록표의 신빠람 사물 초·중급과 연결했다. 나머지도 등록 프로그램 이름과 대조하고 정규화했다.

## 집계 방법

수기 운영일지의 회차별 출석인원을 직접 판독·전사하고 더한다. 양수 인원이 기록된 유효 수업 기록 수를 수업 횟수로 사용한다. 취소선·휴강은 제외한다. 예: 6쪽 2월18일 사물놀이 중급의 14명 기록은 설 연휴로 취소선 처리되어 출석과 횟수에서 제외했다. 3월 실용영어는 87·88쪽의 서로 다른 날짜 12회로 이어지므로 두 페이지를 하나의 프로그램·월로 합친다.

풀잎합창단은 강사별 같은 수업 일지가 2장씩 작성되어 있어 다음 8개 쌍을 각각 한 번만 집계한다: 9/10,47/48,102/103,149/150,196/197,266/267,278/279,324/325쪽. 서로 다른 인원이 있는 7월7일 32/35명과 9월29일 38/36명은 **사용자가 더 많은 인원으로 집계하도록 확인**했으므로 35명/38명을 사용한다. 두 페이지를 더하거나 두 회로 세지 않는다. 정정 필기는 원본 확대 확인 후 최종 숫자를 반영했다.

수납자 기준 출석 기준 연인원 = 11월4일 현재 수납인원 × 확인된 수업 횟수. 평균 출석률은 조회 범위의 참여 합계/기준 연인원 합계인 가중평균이다. 결석 = max(0, 기준 연인원 - 참여 합계); 결석률은 결석/기준 연인원이다. 분모0·자료 미제공은 —로 표시한다. 현재 수납인원 기준으로 100% 초과가 발생해도 원본 출석을 줄이지 않는다. 과거 등록 변동을 반영한 확정 결석 자료가 아닌 참고 지표이다.

## 데이터와 화면

`manual-attendance.json`에는 프로그램명·집계 인원·회차 수·근거 페이지·판독한 회차별 숫자 및 출처 해시만 있다. 강사 이름, 서명, 개인 회원번호나 스캔 원본은 공개 코드에 넣지 않는다. 원본 이미지 및 OCR/전사 작업 파일은 `.tools`의 로컬 자료이다.

화면은 전체/RF/수기 필터와 해당 분류 내 프로그램 선택을 제공한다. 분류를 바꾸면 프로그램 선택을 전체로 초기화한다. 두 표와 지표, 비교 그래프, CSV에 분류 필터가 적용된다. 월별 추이는 선택한 분류·프로그램에 대해 1~10월 전체를 보여준다. 프로그램별 표는 월별 표보다 위에 있고 기존 출석률/결석률 정렬을 유지한다.
