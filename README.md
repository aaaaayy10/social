# 노년사회화교육사업

노년사회화교육 프로그램의 신청·수납 현황과 성별·연령별 이용 분석 대시보드입니다.

## 실행

Node.js 22 이상에서 npm ci, npm run dev를 실행하세요.
기존 Windows 설치 환경에서는 start-local.cmd를 실행할 수 있습니다.

## 환경변수

.env.example을 참고해 .env.local 또는 Vercel 환경변수를 설정하세요.
관리자 비밀번호와 Supabase 서버 키는 저장소에 올리지 않습니다.

## 데이터

프로그램 신청·수납 현황은 2026년 10월 22일 기준 PDF 자료입니다.
성별·연령별 현황은 별도로 제공된 표에 기반하며 집계 기간은 미제공입니다.
