# 노년사회화교육사업

프로그램 등록·수납 현황과 이용자 구성, 환불보고서를 분석하는 내부 운영 대시보드입니다.

## 데이터 기준

세 화면은 2026년 11월 4일 제공된 PDF 세 개를 기준으로 갱신했습니다.

- 프로그램 현황: 현재 45개 강좌의 등록인원 합계(등록 연인원) 1,318명.
- 명부: 이용자 중복 제외 945명, 고유 이용자·강좌 조합 1,810개, 수납 기록 2,645건.
- 표시 금액: 지정한 환불·수납 PDF의 입금액 13,680,000원, 환불액 10,596,200원, 차인잔액 3,083,800원.

집계 기간과 모집단이 다르므로 현재 등록 인원과 명부 실인원을 같은 범위로 간주하지 않습니다. 실제 출석 연인원은 자료가 없으며, 사용자 지정 조건(8개월·월평균 4.35주·주 1.5회)으로 추정 참여 연인원 68,800명·회를 별도 표시합니다. 자세한 출처·검산·계산 기준은 docs/PROGRAM_DETAIL_ANALYSIS.md를 참고하세요.

## 실행

Node.js 22 이상에서 npm ci, npm run dev를 실행하세요. 이 Windows 환경에서는 start-local.cmd를 사용할 수 있습니다.

.env.example을 참고해 환경변수를 설정하세요. 관리자 비밀번호와 Supabase 서버 키, 원본 개인정보는 저장소에 올리지 않습니다.
