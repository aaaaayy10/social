# 노년사회화교육사업

프로그램 등록·수납 현황과 이용자 구성, 환불보고서를 분석하는 내부 운영 대시보드입니다.

## 데이터 기준

세 화면은 2026년 11월 4일 제공된 PDF 세 개를 기준으로 갱신했습니다.

- 프로그램 현황: 현재 45개 강좌의 등록인원 합계(등록 연인원) 1,318명.
- 명부: 이용자 중복 제외 945명, 이용자+강좌 중복 제외 합계 1,810명, 수납 기록 2,645건.
- 환불보고서: 별도 기간 누계 456명과 환불·입금·차인잔액.

집계 기간과 모집단이 다르므로 현재 등록 인원과 명부 실인원을 같은 범위로 간주하지 않습니다. 출석 연인원은 자료가 없습니다. 자세한 출처·검산·계산 기준은 docs/PROGRAM_DETAIL_ANALYSIS.md를 참고하세요.

## 실행

Node.js 22 이상에서 npm ci, npm run dev를 실행하세요. 이 Windows 환경에서는 start-local.cmd를 사용할 수 있습니다.

.env.example을 참고해 환경변수를 설정하세요. 관리자 비밀번호와 Supabase 서버 키, 원본 개인정보는 저장소에 올리지 않습니다.
